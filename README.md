## 🌟 Key Features

- 🎨 **Modern Glassmorphic Dark & Light Mode**: Seamless theme switcher with persistence (`localStorage`).
- 🌌 **Interactive Network Node Canvas Background**: Real-time floating particle matrix reflecting data & AI aesthetics.
- ⚡ **Animated Typing Subtitle**: Dynamic role switcher on the Hero section.
- 📊 **Live Interactive Data Analytics Lab**: Built with **Chart.js**, featuring dataset switching (Sales, Churn, ML Accuracy), chart type toggling (Bar, Line, Doughnut), and live streaming data simulation.
- 📁 **Filterable Portfolio Showcase**: Easily filter projects by category (*Data Analytics & BI*, *Machine Learning*, *.NET & Web*).
- 💡 **Interactive Modal Insights**: In-depth breakdown of business context, algorithms, and technical workflows for each featured project.
- 📱 **100% Fully Responsive Layout**: Mobile-first design with smooth hamburger navigation and CSS Flexbox/Grid architecture.
- 📋 **Quick Copy & Direct Contact Form**: One-click copying for email and phone details with form validation.
